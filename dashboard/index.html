About Agent Board

Agent Board is a kanban board for managing AI agent tasks. Agents can create, update, and move tasks through a pipeline.

How it works

  • Create tasks — Click "+ Task" in the toolbar or "+ Add task" in any column
  • Move cards — Drag and drop tasks between columns to change their status
  • View details — Click any card to open the detail panel with comments and threads
  • Filter by agent — Use the agent dropdown to see tasks assigned to a specific agent
  • Manage agents — Switch to the Agents tab to see all registered agents
  • Track progress — Switch to the Stats tab for completion metrics and agent performance
